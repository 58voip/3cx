# AI Agent 0.9

Sanitized reference release for a Node.js AI voice assistant.

Download the release archive `aiagent-v0.9-public.tar.gz` from this branch. It includes realtime voice, voice task creation, voice analysis, callback workflows, and multi-user isolation.

This public edition keeps configuration interfaces for 3CX, MCP, Qwen, DeepSeek, weather, and stock integrations. MCP OAuth and administrator fallback logic are intentionally omitted; use tenant-owned configuration and token-based MCP access.

No production IDs, API keys, OAuth grants, call records, transcripts, recordings, or credentials are included.
